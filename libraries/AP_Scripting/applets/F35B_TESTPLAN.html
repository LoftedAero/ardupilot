Setup

Run with DOOR_DEBUG = 1 so the script narrates every decision. Load your F-35B params (or the closest tiltrotor + dedicated-lift model) so DOOR_TILT_FN and DOOR_LIFT_FN move — Group 1 verifies these first.

  • Launch: Tools/autotest/sim_vehicle.py -v ArduPlane -f quadplane --console --map
  • Selector (ch 8): rc 8 1000 QSTABILIZE · rc 8 1500 QLOITER · rc 8 2000 FBWA
  • Override (FLTMODE_CH ≠ 8): rc <ch> <pwm> to FBWA / MANUAL
  • GCS mode: mode QHOVER · arm/disarm: arm throttle / disarm
  • Signals: DOOR_ST (0 closed/1 partial/2 open/3 opening), DOOR_PWM, VTOL_DLY, TILT_POS (tilt PWM), LIFT_PWM. These are NAMED_VALUE_FLOAT — if MP doesn't list them, read the ~2 s heartbeat in Messages: F35B hb st=S t=T l=L as=A.
